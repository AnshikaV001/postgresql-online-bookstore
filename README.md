# postgresql-online-bookstore
A PostgreSQL-based Online Bookstore Database Management System for managing books, customers, orders, inventory, and analyzing sales data using SQL queries.

Project Overview

The Online Bookstore Database provides a structured way to store and manage information about:

📖 Books and their details
👤 Customers
🛒 Customer orders
📦 Book inventory and stock
💰 Sales and revenue
📊 Customer and product-level analysis

The project focuses on using SQL to perform both data management and business-oriented analysis.

🛠️ Technologies Used
PostgreSQL
SQL
pgAdmin 4

If you find this project useful, feel free to explore the SQL queries and database structure.
